        <section id="intro">
            <h2>一、球場簡介</h2>
            <p>
                台中洲際棒球場位於台中市北屯區，
                是台中市重要的棒球運動場館，也是台灣舉辦國際級棒球賽事的重要場地之一。
                球場於 <strong>2006 年完工</strong>，
                位於崇德路與環中路口，採用美式風格作為球場設計概念，
                看台視野較為開闊，周邊也保有較大的場地空間。
            </p>
            <p>
                洲際棒球場最具辨識度的特色之一，
                是球場上方以<strong>棒球縫線</strong>為設計概念的景觀造型，
                使球場除了提供比賽使用之外，也成為台中的棒球地標。
            </p>
            <p>
                洲際棒球場曾舉辦多項國際棒球賽事，
                也是國內職業棒球與國際棒球活動的重要場地。
                對喜歡棒球的球迷來說，
                到洲際棒球場看球不只是觀看比賽，
                也是感受台中棒球文化的一種方式。
            </p>
            <p>
                球場地址：台中市北屯區崇德路三段 835 號。<br>
                球場電話：04-2422-1588。<br>
                球場位置：崇德路與環中路口附近。
            </p>
        </section>

        <section id="highlights">
            <h2>二、球場特色與參觀重點</h2>
            <h3>值得留意的三個特色</h3>
            <ul>
                <li>
                    <strong>國際標準球場：</strong>
                    洲際棒球場是台灣重要的國際級棒球比賽場地之一，
                    曾舉辦多項國際棒球賽事。
                </li>
                <li>
                    <strong>美式球場風格：</strong>
                    球場以美式風格為設計架構，
                    看台視野開闊，周邊腹地也較為寬廣。
                </li>
                <li>
                    <strong>棒球縫線造型：</strong>
                    球場上方的景觀設計以棒球縫線為概念，
                    成為洲際棒球場具有代表性的建築特色。
                </li>
            </ul>
            <h3>建議參觀順序</h3>
            <p>
                以下是本報導規劃的參觀建議，並非官方指定路線。
            </p>

            <ol>
                <li>
                    抵達球場後，先觀察球場外觀與具有棒球縫線意象的屋頂設計。
                </li>
            <li>
                    進入球場後，可以觀察球場看台、內野與外野的空間配置。
                </li>

                <li>
                    若當日有棒球賽事，可以透過現場比賽了解職業棒球的觀賽文化。
                </li>
                <li>
                    離開前可以參觀球場周邊的洲際棒球文創園區，
                    認識棒球與休閒活動結合的城市空間。
                </li>
            </ol>
        </section>
